# Fedora Icons mark

`mark-regular.svg` and `mark-filled.svg` are the first-party Fedora Icons mark,
exported unmodified (except `#212121` paint -> `currentColor`) from the Fedora
Icons Figma file `5zcUV9E4Bu8FSssDfhyOWw`, component set `fedora-icons`
(`71:151203`; Regular `71:151173`, Filled `71:151178`) on 2026-11-11.

The mark is the website's identity. It is not part of the four-style SVG core,
the React package, or the Brands catalog, and it is not offered for download.

The header draws the mark in the heading ink color (`--c-ink`), following Light
and Dark. `public/favicon.svg` is the Filled mark with the same ink colors
(`#212121`, `#F2F2F2` under `prefers-color-scheme: dark`) embedded, since a
favicon cannot inherit page colors.
